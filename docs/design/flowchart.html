THE FIVE FLAGS, ANSWERED

The Figma has no connector arrows, so every edge above was read off left-to-right adjacency. Five were flagged as inference. All five now have an answer and are drawn. Two of them need frames before the graph is complete.

ANSWERED
Create New MesoCycle
Not a separate journey — it is Getting Started, Phase 3, reached a second way. The difference is entry: you can start one mid-cycle by returning to the Change It Up hub, so the graph now carries a return edge from the hub up into Phase 3.
ANSWERED
Timer → next set
Two ways out, same destination: the countdown reaches 0:00, or the user taps Continue. Either returns to Log a Set. In a mesocycle that loop runs until the sets are exhausted, then the next exercise takes over — the second loop beneath the engine.
ANSWERED · NOT DRAWN
Select a Plan → preset
A preset drops you at the very end of Create Plan: the whole workout as a summary. Accept takes it as-is; click any row and you are editing like anyone who built it by hand. Waiting on the plans themselves — first one is a 5×5.
ANSWERED
Watch ↔ phone
Finish lands on Summary / Session Done, and Session Done returns to the opening tiles. Both surfaces close the same way, so the graph now runs the watch summary and the phone summary back to their hubs.
ANSWERED · NOT DRAWN
Watch swipe panels
Actions do sit to the left of the set screen, as a swipe. The top swipe is missing from the file: swipe up to adjust the weight — Edit Weights’ job, done in a watch-sized UI. Drawn here as a pending node.
READING NOTES
Chips collapse variants of one frame. Confirm Email Timer is drawn four times in the file across two journeys; it is one screen with a cooldown state, so it appears twice here — once per journey — with the resend state as a chip. Add Exercise Details and its override-applied twin are one node. The three Edit Weights frames and the three timer heart-rate frames are one node each.
Two frames still carry default Figma names — Android Compact – 2 and Android Compact – 3, both recovered-timer states. They are folded into Post Set Timer as the green chip.
