WHERE V1 AND THE FIGMA DISAGREE

Eight things. The first five I have already resolved in favour of the file. The last three need you.

RESOLVED · FILE WINS
Journeys, not stages
V1 ran a single funnel, Stage 0 through Stage 7. The file has ten named parallel journeys with no through-line between them. V2 uses the file's rows.
RESOLVED · FILE WINS
Plan choice is an onboarding screen
V1 gave "Choose a plan" its own stage with a populated-versus-empty fork. In the file, Select a Plan is simply the fourth Onboarding screen, with eight cards drawn including Build My Own Plan.
RESOLVED · FILE WINS
No Units screen
V1 had Units as a required, unskippable first preference. The file has no such screen — Lbs/Kgs is a toggle inside Setup, alongside experience level.
RESOLVED · FILE WINS
Progression override is drawn
V1 parked per-lift overrides at V1.1. The file has three override screens: Progression Override and its applied state inside Getting Started, plus Pacing Override in Next Workout.
RESOLVED · FILE WINS
Freestyle is a first-class journey
V1 treated freestyle as an escape hatch mentioned in three places. The file gives it nine screens, ending in Session Done with the option to fold the session into a plan.
NEEDS YOUR CALL
Create New MesoCycle is one screen
The journey is labelled and started, then stops at Change It Up. Getting Started downstream appears to be the real build flow. Is Create New MesoCycle a duplicate to delete, or an editing path still to be drawn?
NEEDS YOUR CALL
Google sign-in
The file draws Continue with Google on Login and Sign up with Google on Create Account. V1 said the button was drawn but the wiring off. Does it work at launch?
NEEDS YOUR CALL
Two names for the product
The splash wordmark reads WOLFSET. The welcome copy four screens later reads "Welcome to Gym Wolf". One of them is stale.

NOTES ON THIS TRACE
Rows are ordered by their vertical position in the file and screens by their horizontal position, so the sequence you see is the sequence you drew. No connector arrows exist in the file — the arrows here are read off left-to-right adjacency, which is why the two loops and the Pacing Override placement are called out rather than assumed.
Two frames still carry default Figma names, Android Compact – 2 and Android Compact – 3. Both are rest-timer states. Renaming them would make this trace stable across future exports.
Quoted text is verbatim from the file, including the annotations you wrote on the canvas. Type is set in Barlow here because Geom is not available on the web — the sizes and colours are the file's.
